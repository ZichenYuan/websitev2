About

Hi there! I'm a builder at heart — happiest turning hard problems into things that actually work. I love going deep, learning fast, and making stuff at the frontier of AI — lately that means robots and the edge hardware they run on.

I'm a software engineer at Microsoft Azure, where I ship GPU/accelerator enablement for a managed Kubernetes platform running at carrier scale — the kind of low-level systems work that lets customers run real AI workloads.

My edge is range — from Linux drivers and GPU passthrough up through Go control planes and Kubernetes operators, rounded out with hands-on reinforcement learning and LLM-agent research. Next: bringing those systems instincts to Physical AI and the constrained hardware robots run on. You can see what I've built in the projects section.

Status: open to what's next.

AI Infrastructure

The substrate AI runs on: GPU/accelerator enablement on Kubernetes (drivers, PCI passthrough, device plugins, NVIDIA GPU Operator), LLM inference serving with vLLM — OpenAI-compatible endpoints, continuous batching, KV cache — edge model serving on constrained hardware, and the Go control planes and GPU-aware scheduling that tie it together.
